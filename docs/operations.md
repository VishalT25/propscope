# Operations

Golden rule: a page request never calls an external API. Jobs fetch, pages read.

## Live data switch
Nothing touches the network unless `LIVE_DATA=true`. In development and test, every capability is served by the fixture provider (`config/providers.yml`). In production, live jobs no-op until `LIVE_DATA=true` and the API keys in `.env.example` are set.

## Jobs (config/recurring.yml, production, US Eastern)
| Job | Schedule | What it does |
|---|---|---|
| `SyncReferenceDataJob` | 06:00 daily | Teams, players, next 7 days of games (BallDontLie). |
| `IngestGameLogsJob` | 04:00 daily | Yesterday's box scores. `perform_now(date)` to run another day. |
| `SnapshotOddsJob("morning")` | 10:00 | Whole 36h window. **Optional**: dropped at 80% of budget. |
| `SnapshotOddsJob("afternoon")` | 15:00 | Same. Optional. |
| `SnapshotOddsJob("tick")` | every 10 min | Fetches only games at T-90 (optional), T-20 and tip (always kept). Usually a no-op. |
| `MarkClosingLinesJob` | every 10 min | Flags the last pre-tip snapshot as closing. |
| `ComputeDefenseRanksJob` | 04:30 daily (also after each stats ingest) | Defence vs position ranks from our own logs. |
| `PrecomputeHitRatesJob` | 04:45 daily (also after each odds snapshot and stats ingest) | `prop_hit_rates` for every upcoming player prop, both sides. Pages read this table. |
| `GenerateInsightsJob` | 04:50 daily (also after each hit-rate run) | Runs the five insight rules over every upcoming prop and replaces that slate's insights. |
| `PurgeRawPayloadsJob` | 05:30 daily | Deletes raw payloads older than 14 days. |

Jobs are idempotent: running any twice creates no duplicates (covered by specs).

## Budget
`api_usages` tracks units per provider per month. SportsGameOdds: 2,500 objects/month; warn and drop optional snapshots at 80%; refuse (`BudgetGuard::BudgetExceeded`, handled in jobs) at 100%. A `budget_warning.propscope` notification fires when crossing 80%.

## Rake tasks
| Task | Notes |
|---|---|
| `data:seed_fixtures` | Loads the synthetic sample slate. Also run by `db:seed` outside production. |
| `data:backfill_logs SEASONS=2` | Needs `LIVE_DATA=true` and a BallDontLie ALL-STAR key. Resumable. |
| `data:capture_fixtures` | Needs `LIVE_DATA=true`. Records a small real sample over the synthetic one. Review before committing (provider terms forbid bulk data). |
| `data:renormalize PROVIDER=... SINCE=...` | Re-parses stored raw payloads. No API calls, no budget. |

## Fixtures
`spec/fixtures/providers/**` are synthetic (fictional players, real team names), generated by `script/generate_sample_fixtures.rb` in the documented vendor shapes, and replayed through the real adapters' parsers. Dates are shifted at load so the sample slate is always today.
